# Priyanka M — React Portfolio

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. Run:
   npm install
   npm run dev
4. Open the localhost URL shown by Vite.

## Build
npm run build

## Customize
- Edit `src/App.jsx` for portfolio text, projects, achievements and links.
- Edit `src/styles.css` for the visual theme.
- Replace the placeholder project media blocks with screenshots, videos, Figma embeds, or project links.
- The uploaded resume is included as `public/Priyanka_M_Resume.pdf`.

## Included pages
- Home
- Figma Projects
- Unity 3D Projects
- Work Projects (AmsonWebz)
